# Beasts website

The website for **Beasts**, a pond that evolves without you: tiny creatures built from cells swim, graze, breed and evolve on their own, while tardigrades hunt them. Free to play in your browser, or download it for Mac, Windows and Linux.

**Play:** https://beasts.marmonte.ai

- `index.html`: the home page
- `help.html`: how to play, with every control
- `img/`: screenshots and art

The browser game and the desktop downloads are added when the site is deployed; they aren't in this repo.

## See it locally

```sh
python3 -m http.server 8766
```

Then open http://localhost:8766. "Play" needs the browser game in `play/`, which comes with a deploy.
